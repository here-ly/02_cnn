# METHODOLOGY.md 模板

每个项目根目录必须包含 `METHODOLOGY.md`，记录该项目的专有信息。**只写该项目的公式、设计和决策**，不写通用教科书内容。

## 必含章节

| 章节 | 内容 |
|------|------|
| 问题定义 | 本项目要解决什么问题、MDP 五元组（RL）/ input-output（DL） |
| 公式 | 该项目的奖励函数定义、loss 公式、预处理公式 |
| 网络结构 | 当前使用的网络结构图 + 参数量估算 |
| 设计决策 | 为什么选这个网络 / 奖励函数 / 超参范围？踩过什么坑 |
| 全链路说明 | 从 notebook 到 scripts 本项目各文件的作用 + 运行命令 |
